# Sami Rahni - Personal Portfolio

> **Software Engineer | Data & AI | Full-Stack & Microservices**

Premium, modern, and high-performance portfolio application built for **Sami Rahni**, Software Engineering Student at EMSI (Master 1 / 5th Year), specializing in Data & AI pipelines, microservices, Event-Driven Architecture (EDA), and modern full-stack web applications.

## 🚀 Tech Stack

- **Frontend**: React 18, TypeScript, Tailwind CSS, Framer Motion
- **Icons & Visuals**: Lucide Icons, HTML5 Canvas Event Architecture, Interactive Neo4j Airport Graph & RabbitMQ Streaming Pipeline Visualizations
- **Build Tool**: Vite
- **UI Components**: Glassmorphic Navbar, Dark/Light Theme Switcher, Command Palette (`Cmd+K` / `Ctrl+K`), Interactive Resume Viewer & Download Generator, Scroll Progress Bar, Back-To-Top button

---

## 🛠️ Getting Started

### Prerequisites
- Node.js >= 18.x
- npm >= 9.x

### Installation & Execution

```bash
# Install dependencies
npm install

# Run local development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
